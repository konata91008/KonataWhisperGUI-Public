# ============================================================
# WhisperGUI (TJKSub) — Python 套件需求
# 建議 Python 版本：3.10 ~ 3.12（開發/測試環境：3.12，見 venv/pyvenv.cfg）
# 安裝方式：pip install -r requirements.txt
#
# [版本相容性說明]
# PyQt5 相關套件改用「版本範圍」而非固定版本。
# 原因：PyQt5-sip 是依 Python 版本編譯的二進位套件，
#   - 12.18.0 只支援 Python >= 3.10（PyPI requires_python 已查證）
#   - Python 3.8 / 3.9 需退回 12.13 等舊版
# 固定死版本會讓不同 Python 版本的電腦安裝失敗，
# 改用範圍後 pip 會依當前 Python 自動挑選可用版本。
# ============================================================

# --- GUI 框架（main.py / gui/ 內以 PyQt5.QtWidgets, QtCore, QtGui 等模組匯入）---
PyQt5>=5.15.10,<5.16
PyQt5-sip>=12.13,<13
PyQt5-Qt5>=5.15.2,<5.16
